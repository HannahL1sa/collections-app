# Collections App

A collections workflow management system that automates client outreach decisions based on invoice aging. It replaces a manual Excel-based process by calculating overdue days, determining appropriate outreach actions, and logging communications for audit and tracking.

## ✨ Features

- **Invoice Aging:** Calculate the number of days invoices are overdue.
- **Automated Outreach Decisions:** Determine the appropriate outreach action based on invoice aging rules.
- **Client Management:** Organize client information and outstanding invoice records.
- **Communication Logging:** Record client outreach activities for tracking and auditing.
- **Workflow Automation:** Reduce manual work and improve consistency in the collections process.
- **Audit Trail:** Maintain a record of outreach decisions and communication history.
- **Responsive Design:** Provide a user-friendly experience across different screen sizes.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** ASP.NET Core Web API
- **Database:** PostgreSQL
